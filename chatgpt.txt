❌ Root error
The first compiler error is:
HMorixApp.kt:1:9 Package name must be a '.'-separated identifier list
and the same error appears in:
HMorixApp.kt
HMorixApiService.kt
SessionManager.kt
Models.kt
PortalRepository.kt
MainActivity.kt
and likely other Kotlin files.
The package is apparently:
package in.hmorix.client
Why this breaks
in is a reserved Kotlin keyword.
So Kotlin does not accept:
package in.hmorix.client
even though in is perfectly valid as a Java package component.
That's why the compiler then produces a huge chain of secondary errors such as:
Unresolved reference: SessionManager
Unresolved reference: ApiResponse
Unresolved reference: AuthResponse
Unresolved reference: PortalData
Unresolved reference: Ticket
Unresolved reference: User
Those aren't the original problem. The compiler can't correctly parse the package/import declarations, so it subsequently can't find the classes.
The fix
You have two good options.
Option 1 — escape in:
package `in`.hmorix.client
and imports must similarly use:
import `in`.hmorix.client.data.model.User
This is the smallest change.
Option 2 — better long-term fix: rename the package from in.hmorix... to something that doesn't use a Kotlin keyword, for example:
package com.hmorix.client
Then update the corresponding imports and Android manifest/application references.
Important
The LinearProgressIndicator mentioned in the commit title is not the main build-breaking error shown in this CI run. The build reaches:
> Task :app:compileDebugKotlin
and then fails because of the invalid in package declarations.
So the error chain is essentially:
package in.hmorix.client
        ↓
'in' is Kotlin keyword
        ↓
package/import parsing fails
        ↓
classes cannot be resolved
        ↓
many "Unresolved reference" errors
        ↓
compileDebugKotlin fails
        ↓
BUILD FAIL
